# Точечные исключения Bandit в ЛР4

`src/serve.py`, B104: допустим только явный параметр `--host 0.0.0.0` для интерфейса
контейнера. По умолчанию выбран `127.0.0.1`. Docker публикует порт только через
`-p 127.0.0.1:8000:8000`; в CI проверяется фактический HostIp. Приложение требует
runtime-токены, ограничивает тело, параллелизм и частоту. Исключение не разрешает
публикацию порта хоста на всех адресах.

`src/healthcheck.py`, B310: URL задан константой `http://127.0.0.1:8000/health`,
не берётся из входа или окружения. Читается максимум 1024 байта с timeout 2 с;
секреты не передаются. Проверяется готовность уже запущенного сервера.

Оба исключения хранятся рядом с конкретной строкой как `nosec <ID>`.
Глобальные skips и подавление кодов возврата не применяются.
