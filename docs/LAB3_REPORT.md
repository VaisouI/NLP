# Отчёт по лабораторной работе №3

**Тема:** безопасный CI/CD для NLP-классификатора SMS.
**Дата выполнения:** 01.11.2026.
**Проект:** [VaisouI/NLP](https://github.com/VaisouI/NLP).

## Выполненная работа

Продолжен проект ЛР1–ЛР2: TF-IDF + LogisticRegression, классы ham/spam,
нормализация NFKC/casefold/whitespace, seed 42. Настроен GitHub Actions для push
и pull request. Отдельный сервер CI не разворачивался: проверки реально
выполнены на GitHub-hosted Ubuntu 24.04, Python 3.12.16.
Сохранённая Ubuntu VM ЛР1–ЛР2 не изменялась этим workflow.

Полный последовательный pipeline: получение проверенного источника и подготовка
контрольной выборки → Ruff → Bandit → pytest → pip-audit → data gate → обучение
кандидата только на train → оценка сохранённого кандидата и model gate → Docker
build → Trivy config → Trivy image и security gate → non-root/smoke → отчёты.
При отказе дальнейшие обязательные шаги не выполняются; диагностический upload
работает и при failed. Права — contents:read, таймаут — 25 минут, Actions закреплены
commit SHA; пользовательских secrets, публикации registry и deployment нет.

## Данные и качество модели

Контрольный JSONL воспроизводится из того же проверенного UCI SMS Spam Collection.
Входная схема: source_row — целое неотрицательное, text — непустая строка по
политике ЛР2, target — ham/spam. Ровно 1025 объектов: 897 ham и 128 spam.
Проверяются поля, типы, пропуски/null/NaN/Inf, Unicode, пределы текста,
дубликаты, объём, доли классов, версии источника/разбиения и SHA256.
Правила: `config/data_gate.json`; исходный датасет для отказа не изменялся.

SHA256 `control.jsonl`:

```text
491bfa211530d93e191309882e5ccee0611589b434deb95dc7fce1e2d4952cfd
```

Baseline отдельно хранится в `metrics/baseline_ci.json` и защищён файловым SHA
в политике. CI не перезаписывает baseline и не оценивает финальный test ЛР2.
Новая сериализация воспроизводимого кандидата допускается, но перед оценкой
проверяются её собственные размер/SHA, версия sklearn и допустимые типы skops.

## Тесты и проверки безопасности

Успешный запуск: **87 passed in 0.57s**, Ruff — 0 нарушений,
Bandit — 0 находок, pip-audit — **131 пакет, 0 известных находок, 0 пропусков**.
Тесты проверяют нормализацию и форму результата, отказ до вызова модели,
проверенную загрузку артефакта, известные значения метрик, неизменяемость baseline,
схему/распределение/целостность данных, порог и неверные метрики, правила security
gate и отсутствие автоматического признания UNKNOWN безопасным.
Unit-тесты не скачивают данные и не обучают модель на полном корпусе.

Trivy 0.76.1 установлен из официального release с проверкой SHA256 архива.
Dockerfile scan: **0 ошибок конфигурации**. Image scan завершён успешно;
ошибка базы или scanner process остановила бы pipeline.

В исходном image report найдено **183 записи**: LOW 62, MEDIUM 67, HIGH 46,
UNKNOWN 8, CRITICAL 0. UNKNOWN проверены по опубликованным CVSS CNA/CISA из
одного immutable snapshot CVE Program, с сохранением JSON/URL/commit/SHA:
уточнены 1 LOW, 4 MEDIUM, 3 HIGH. Неразобранных UNKNOWN — 0.
Находки не удалены из Trivy JSON; уязвимости ниже CRITICAL остаются известным
риском и допускаются заявленной минимальной политикой работы.

Политика: любая находка/пропуск/ошибка pip-audit блокирует сборку; для образа
блокируются CRITICAL и UNKNOWN без проверяемой оценки; для Dockerfile — все
находки. Исходный CRITICAL не понижается, при нескольких первичных оценках
выбирается наиболее строгая severity. Allowlist CVE и `.trivyignore` не используются.
Пример разбора: [CVE-2026-82560](../security/CVE-2026-82560-review.md).

## Контейнер

Базовый официальный образ — `python:3.12.16-slim-trixie`. В образ передаются
только inference-модули, конфигурация, кандидат и отдельный SHA-манифест;
устанавливаются 11 зафиксированных runtime-зависимостей. Jupyter и средства
обучения/аудита не устанавливаются как отдельные инструменты контейнера.
`.dockerignore` разрешает только необходимые пути.

Фактический UID внутри контейнера — **10001**, директива USER задана.
Smoke реально загрузил модель и вернул `ham` для сообщения о встрече и `spam`
для сообщения о выигрыше. Запуск использовал network=none, read-only filesystem,
cap-drop=ALL, no-new-privileges, пределы CPU/памяти/процессов. Docker socket не
подключался, privileged не использовался. Команды приведены в [LAB3.md](LAB3.md).
